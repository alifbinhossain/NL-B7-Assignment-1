## Blog Posts

### `blog-1.md` — `any` vs `unknown` and Type Narrowing
Explains why `any` is considered a type safety hole, how `unknown` forces explicit type checks before use, and how type narrowing (`typeof`, `instanceof`, type predicates) lets TypeScript refine types at runtime boundaries.

### `blog-2.md` — Generics and Reusable Typed Components
Covers how generic type parameters allow writing flexible, reusable components without sacrificing type safety — illustrated with a real `ApiResponse<T>` interface from a hobby project.
